실행 방법 (run.sh)

기본 실행 — pbmm2부터 전체 파이프라인

bash run.sh --samplesheet input/samples.csv

결과 경로 지정

bash run.sh \ --samplesheet input/samples.csv \ --outdir /data/K_map/results

중단된 파이프라인 재시작 (-resume)

bash run.sh \ --samplesheet input/samples.csv \ -resume # Nextflow 캐시를 재사용 — 완료된 스텝은 건너뜀

hiphase 단계부터 재시작

# samplesheet의 start_step=hiphase 로 설정 후: bash run.sh \ --samplesheet input/samples_hiphase.csv \ --vcf_dir /data/results/HG002 \ -resume # --vcf_dir: 기존 DV/SAWFISH/TRGT VCF가 있는 디렉토리

GPU 없이 실행 / 스레드 수 조정

bash run.sh \ --samplesheet input/samples.csv \ --use_gpu false \ --threads 32

XX 샘플 (여성) 실행

bash run.sh \ --samplesheet input/samples.csv \ --karyotype XX # TRGT의 성별 설정 — XY(기본) 또는 XX

SLURM 클러스터 실행

bash run.sh \ --samplesheet input/samples.csv \ -profile slurm
파라미터 전체 목록
파라미터기본값설명
--samplesheet 필수 입력 CSV 파일 경로 (sample_id, bam, start_step)
--outdir <pipeline_dir>/results 결과 출력 디렉토리
--threads 16 CPU 스레드 수 (high_mem 라벨 프로세스에 적용)
--use_gpu true DeepVariant GPU 사용 여부 (false 시 CPU 모드)
--karyotype XY TRGT 성별 설정 — XY 또는 XX
--vcf_dir null start_step=hiphase 시 기존 VCF 경로 (지정 안 하면 outdir 사용)
--ref auto GRCh38_no_alt_analysis_set.fna — pipeline_dir 기준 자동 설정
--ref_mmi auto pbmm2 인덱스 (.fna.mmi) — 자동 설정
--trgt_catalog auto TRGT 반복서열 카탈로그 (repeat_catalog.hg38.bed)
--te_fasta auto sTELLeR TE 레퍼런스 (teref.human.fa)
--steller_py auto sTELLeR 메인 스크립트 경로
--vep_cache auto Ensembl VEP 오프라인 캐시 디렉토리
--annotsv_db auto AnnotSV 데이터베이스 디렉토리

주요 사항
GRCh38 no-alt 사용 필수
GRCh38 primary assembly (with alt contigs) 사용 시 DeepVariant가 unplaced contig에서 0바이트 VCF shard를 생성하며 exit 245 (SIGSEGV) 발생. GRCh38_no_alt_analysis_set만 사용할 것.
DeepVariant → SAWFISH → TRGT 순차 실행
채널 join()으로 순서가 코드 레벨에서 강제됨. DV VCF가 emit되어야 SAWFISH 시작, SAWFISH stats.json이 emit되어야 TRGT 시작.
pb-CpG-tools 출력 → MethBat 연계
combined.bed.gz / hap1.bed.gz / hap2.bed.gz (type 컬럼: Total/hap1/hap2).
MethBat segment: methbat segment --input-prefix {sample_id 경로 prefix}
MethBat joint-segment: 샘플 목록 TSV (identifier / filename / labels) → methbat joint-segment --input-collection collection.tsv
workDir 로컬 SSD 고정
NFS 위에서 samtools sort 임시 파일 truncation 문제 방지를 위해
workDir = /home/Data_Drive_8TB_2/senc0711/K_map_nf_work_v2 고정.
sTELLeR 출력 파일명
-o {prefix} 옵션이 파일명이 아닌 sample prefix로 작동 → 실제 출력: {prefix}_repeats.vcf. TE 이름에 콜론 포함 시 FORMAT 필드 fix 자동 적용 (awk).
메모리 로그 위치
• outdir/logs/system_memory.tsv — run.sh 백그라운드 루프가 5초 간격으로 기록. 파이프라인 종료 시 자동 중지.
• outdir/pipeline_info/trace.csv — Nextflow가 프로세스별 CPU/메모리를 자동 기록 (peak_rss 포함).
• outdir/{sample_id}/logs/pipeline_done.tsv — 파이프라인 완료 시점 스냅샷.
