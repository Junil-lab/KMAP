scRNA-seq Preprocessing and QC Pipeline

Takes 10x Genomics FASTQ, runs Cell Ranger, CellBender, Scanpy and SOLO in order, and writes the QC-passed matrix, doublet annotation, singlet-only matrix and a per-sample QC summary.

Workflow: Nextflow Runtime: Singularity / Apptainer SIF Default mitochondrial filter: pct_counts_mt < 20 Default HVG: 2,000 genes

Required Inputs

  • 10x FASTQ directory
  • 10x Cell Ranger transcriptome reference
  • samplesheet CSV with sample_id, fastqs, sample, transcriptome

Main Processing

  • Cell Ranger count
  • CellBender ambient RNA correction
  • Scanpy QC and HVG selection
  • SOLO doublet detection and filtering

Key Final Outputs

  • SOLO-annotated full H5AD
  • SOLO singlet-only full H5AD
  • Integrated QC summary CSV

Final Output Interpretation

03_scanpy_qc/*_qc_full.h5ad
Full-gene matrix that passed mitochondrial / gene count / UMI count QC. No SOLO labels yet.
03_scanpy_qc/*_qc_hvg2000.h5ad
HVG subset for SOLO doublet detection. Not the full matrix for final analysis.
05_singlets/*_qc_solo_annotated_full.h5ad
Full-gene H5AD keeping every QC-passed cell, with SOLO doublet labels and scores added to obs.
05_singlets/*_qc_solo_singlets_full.h5ad
Singlet-only full-gene H5AD with SOLO doublets removed; the final matrix for downstream analysis.
scrnaseq_qc_summary.csv
Summary table for all samples: cell counts, mitochondrial QC, SOLO doublet counts, singlet counts, etc.
