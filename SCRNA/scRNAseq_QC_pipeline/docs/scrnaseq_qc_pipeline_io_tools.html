scRNA-seq Preprocessing and QC Pipeline

10x Genomics FASTQ를 입력으로 받아 Cell Ranger, CellBender, Scanpy, SOLO를 순차적으로 실행하고, QC 완료 matrix, doublet annotation, singlet-only matrix, 샘플별 QC summary를 생성하는 워크플로우입니다.

Workflow: Nextflow Runtime: Singularity / Apptainer SIF Default mitochondrial filter: pct_counts_mt < 20 Default HVG: 2,000 genes

Required Inputs

  • 10x FASTQ directory
  • 10x Cell Ranger transcriptome reference
  • samplesheet CSV with sample_id, fastqs, sample, transcriptome

Main Processing

  • Cell Ranger count
  • CellBender ambient RNA correction
  • Scanpy QC and HVG selection
  • SOLO doublet detection and filtering

Key Final Outputs

  • SOLO-annotated full H5AD
  • SOLO singlet-only full H5AD
  • Integrated QC summary CSV

Step4 HVG selection for SOLO {sample}_qc_full.h5ad {sample}_qc_hvg2000.h5ad Scanpy SOLO doublet detection에 사용할 highly variable genes를 기본 2,000개 선택합니다.

Step6 Transfer SOLO labels to full matrix {sample}_qc_full.h5ad
{sample}.solo/soloed.h5ad 		{sample}_qc_solo_annotated_full.h5ad filter_solo_singlets.py + AnnData QC를 통과한 모든 cell을 유지한 full-gene H5AD에 solo_is_doublet, solo_softmax_scores, solo_logit_scores를 추가합니다.
Step7 Remove SOLO doublets {sample}_qc_solo_annotated_full.h5ad {sample}_qc_solo_singlets_full.h5ad
{sample}.solo_doublet_barcodes.csv

Step8 Merge QC summaries {sample}.qc_metrics.csv
{sample}.solo_summary.csv 		scrnaseq_qc_summary.csv merge_qc.py 샘플별 QC 지표와 SOLO doublet summary를 하나의 통합 table로 병합합니다.

Final Output Interpretation

03_scanpy_qc/*_qc_full.h5ad
미토콘드리아/유전자 수/UMI count QC를 통과한 full-gene matrix입니다. SOLO label은 아직 포함되지 않습니다.
03_scanpy_qc/*_qc_hvg2000.h5ad
SOLO doublet detection용 HVG subset입니다. 최종 분석용 full matrix는 아닙니다.
05_singlets/*_qc_solo_annotated_full.h5ad
QC-passed 모든 cell을 유지하면서 SOLO doublet label과 score를 obs에 추가한 full-gene H5AD입니다.
05_singlets/*_qc_solo_singlets_full.h5ad
SOLO doublet cell을 제거한 최종 downstream analysis용 singlet-only full-gene H5AD입니다.
scrnaseq_qc_summary.csv
모든 샘플의 cell count, mitochondrial QC, SOLO doublet count, singlet count 등을 통합한 summary table입니다.
